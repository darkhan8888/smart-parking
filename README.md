# Smart Parking | Умная парковка

Интерактивный учебный проект автоматической парковки со шлагбаумом. Работает прямо в браузере, сервер и установка библиотек не требуются.

## Возможности

- 12 парковочных мест с наглядной схемой.
- Автоматический въезд по номеру машины, выбор первого свободного места.
- Запрет въезда и закрытый шлагбаум, когда парковка заполнена.
- Запрет повторного въезда автомобиля с тем же номером.
- Выезд автомобиля по номеру и освобождение его места.
- Анимация открытия и закрытия шлагбаума.
- Статистика загруженности и журнал последних 30 событий.
- Сохранение данных в `localStorage` между перезагрузками браузера.
- Сброс демонстрации и адаптация под телефон.

## Запуск

1. Скачайте проект или выполните `git clone https://github.com/USERNAME/smart-parking.git` (замените `USERNAME` на свой логин).
2. Откройте файл `index.html` в браузере.
3. Введите, например, `123 ABC 02` и нажмите «Въезд автомобиля».
4. Повторяйте с разными номерами. На 13-й машине система откажет во въезде.
5. Чтобы освободить место, нажмите на занятую ячейку и выберите «Выезд автомобиля».

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий с именем `smart-parking`.
2. Загрузите **содержимое** папки `smart-parking` в корень репозитория (файл `index.html` должен находиться в корне).
3. Перейдите в **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
5. Ссылка на сайт появится в настройках Pages. Обычно адрес выглядит как `https://USERNAME.github.io/smart-parking/`.

## Сценарий демонстрации преподавателю

1. Показать 12 свободных мест.
2. Добавить машину и продемонстрировать открытие шлагбаума.
3. Попробовать въехать под тем же номером. Система откажет.
4. Заполнить все 12 мест и попытаться въехать 13-й машиной. Шлагбаум останется закрыт.
5. Выпустить одну машину и показать, что свободное место снова доступно.
6. Обновить страницу и показать сохранение данных.

## Ограничения

Демо моделирует парковку в одном браузере. Нет настоящих датчиков, распознавания номеров, пользователей, сервера и общей базы данных. Для реального шлагбаума потребуются дополнительное оборудование, серверная логика и меры безопасности.
